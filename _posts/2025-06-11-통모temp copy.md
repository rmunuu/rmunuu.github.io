문제 1

소아마비 백신의 효과를 검증하기 위해 다음과 같이 대조군과 처리군에 실험을 진행하였다.



마비 증세 발현 환자 수

표본 크기

대조군

$X_1$

$n_1$

처리군

$X_2$

$n_2$

백신을 접종하지 않은 대조군에서 마비 증세 발현 확률을 $p_1$, 백신을 접종한 처리군에서 마비 증세 발현 확률을 $p_2$ 라고 하자. $n_1 = n_2$ 일 때, 다음의 검정을 수행하려고 한다.

$$H_0: p_1 = p_2 + \delta \quad vs \quad H_1: p_1 < p_2 + \delta
$$이 때 큰 n에서 근사적으로 정규분포를 따르게 되는 검정통계량 $\hat{p} = c \hat{p_1} + (1-c) \hat{p_2}$ 를 만들어 검정을 수행하려고 한다. (편의를 위해 선형결합에서 두 계수의 합이 1이라 가정해도 상관없다.)

$H_0$ 하에서, $Var(\hat{p})$ 을 최소로 만드는 c값을 구하라. $\delta = 0$ 일 때 분산이 최소가 되는 검정통계량이 $\hat{p} = \dfrac{n_1 \hat{p_1} + n_2 \hat{p_2}}{n_1 + n_2} = \dfrac{X_1 + X_2}{n_1 + n_2}$ 임을 확인하라.

### 해설 (Solution)

$\hat{p} = c \hat{p_1} + (1-c) \hat{p_2}$은 충분히 큰 n에서 다음의 분포를 따른다.

$$
\hat{p} \sim N \left( c p\_1 + (1-c) p\_2, \\ c^2 \dfrac{p\_1(1-p\_1)}{n\_1} + (1-c)^2 \dfrac{p\_2(1-p\_2)}{n\_2} \right)
$$

편의를 위해 $p = \dfrac{p_1 + p_2}{2}$ 라 치환하자. $H_0$ 하에서 다음의 분포를 따른다.

$$
\hat{p} \sim N \left( p + (c-\dfrac{1}{2}\delta) , \ c^2 \dfrac{(p+\frac{\delta}{2})(1-(p+\frac{\delta}{2}))}{n_1} + (1-c)^2 \dfrac{(p-\frac{\delta}{2})(1-(p-\frac{\delta}{2}))}{n_2} \right)
$$$

Var(\hat{p})$ 가 최소가 되는 c를 찾자. $Var(\hat{p})$을 c에 대해 편미분하면

$$
\dfrac{\partial Var(\hat{p})}{\partial c} = \dfrac{2(p+\frac{\delta}{2})(1-(p+\frac{\delta}{2}))}{n_1} c - \dfrac{2(p-\frac{\delta}{2})(1-(p-\frac{\delta}{2}))}{n_2} (1-c)
$$

이를 c에 대해 정리하면 다음을 얻는다.

$$
c = \dfrac{
\dfrac{(p-\frac{\delta}{2})(1-(p-\frac{\delta}{2}))}{n_2}
}{
\dfrac{(p+\frac{\delta}{2})(1-(p+\frac{\delta}{2}))}{n_1} + \dfrac{(p-\frac{\delta}{2})(1-(p-\frac{\delta}{2}))}{n_2}
}
$$

$\delta = 0$ 일 때의 상황을 확인해보자. 위의 c에 이를 대입해 정리하면 $c = \dfrac{n_1}{n_1+n_2}$ 를 얻는다. c를 원래의 선형결합 식에 대입하면 $\hat{p} = \dfrac{n_1 \hat{p_1} + n_2 \hat{p_2}}{n_1 + n_2} = \dfrac{X_1 + X_2}{n_1 + n_2}$ 를 확인할 수 있다.

함수 $f$ 는 우리가 관측한 데이터들로 검정통계량을 만든다. 이 검정통계량은 상황을 요약하고, 우리의 귀무가설을 검정할 수 있게 하는 척도이다. 검정통계량은 직관적이지 않을 수 있지만, 중요한 것은 1. 어떤 분포를 따르는지, 2. 검정을 효과적으로 할 수 있는지 이다. 이해를 돕기 위해 다음 문제를 같이 풀어보자.

(서울대학교 통계학 001 2017 기말 2번) 두 모집단의 평균 비율을 위하여 그룹 1으로부터 $X_1, \dots, X_n$의 IID 관측값들을 얻고 그룹 2로부터 $Y_1, Y_2, \dots, Y_n$의 IID 관측값들을 얻었다(수식 전개의 편의성을 위해 $n_1 = n_2$를 가정함). 그룹 1은 $N(\mu_1, \sigma_1^2)$를 따르고 그룹 2는 $N(\mu_2, \sigma_2^2)$를 따른다. 평균과 분산들 모두 미지이고 $\sigma_2^2 = 2\sigma_1^2$이 알려져 있을 때 가설 $H_0 : \mu_1 = \mu_2$ versus $H_1 : \mu_1 \neq \mu_2$에 대한 독립 이표본 $t$-검정에 대해 기술하여라.

우리의 목표: 위의 관측값들로 t분포를 따르는 검정통계량을 찾자. $T = \dfrac{Z}{\sqrt{V/k}} \sim t(k) \quad (\ Z \sim N(0, 1), \ V \sim \chi^2(k))$ 에서 t분포를 분자와 분모로 나눠서 생각하면, 우리는 독립인 정규분포와 카이제곱분포를 찾으면 된다. 정규분포는 쉽게 찾을 수 있다. $\bar{X} - \bar{Y} \sim N \left( \mu_1 - \mu_2, \dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2} \right)$ 이고, 정규화하면

$$
\dfrac{(\bar{X} - \bar{Y}) - (\mu\_1 - \mu\_2)}{\sqrt{\dfrac{\sigma\_1^2}{n\_1} + \dfrac{\sigma\_2^2}{n\_2}}} \sim N(0, 1) \tag{1}
$$
이제 어떤 값이 카이제곱분포를 따르는지 찾아보자. 쉽다. $\dfrac{(n-1)S\_1^2}{\sigma\_1^2} \sim \chi^2(n-1) $ 이잖아? 물론 가능하다. 하지만 우리는 $\sigma_2^2 = 2\sigma_1^2$ 이라는 것을 알고 있기 때문에, *검정을 효과적으로 할 수 있는가* 조건을 생각해 더 좋은 통계량을 잡을 수 있다. $\dfrac{(n-1)S\_1^2}{\sigma\_1^2} + \dfrac{(n-1)S\_2^2}{\sigma\_2^2} \sim \chi^2(2n-2) $ 으로 자유도가 $2n-2$ 인 카이제곱분포를 따르는 통계량을 만들 수 있고, 이를 이용해 T 검정통계량을 만들면 $ t(2n-2)$ 를 이용해 더 좋은 검정을 할 수 있다. 야호 $\sim$

$$
T = \dfrac{\dfrac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{\sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}}}{\sqrt{ \left( \dfrac{(n-1)S_1^2}{\sigma_1^2} + \dfrac{(n-1)S_2^2}{\sigma_2^2} \right) \Bigg/ (2n-2) } }
= \dfrac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{\sqrt{\dfrac{3}{2n} \left( S_1^2 + \dfrac{1}{2} S_2^2 \right) } }
\sim t(2n-2)
$$

이렇게 만들어진 검정통계량을 보면 우리가 익숙한 T 통계량과 조금 다르게 생겼다. 우리는 평소에 T 검정통계량을 만드는 공식인 것처럼, $X \sim N(\mu, \sigma^2) $ 일 때 $T = \dfrac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$ 을 구하지 않았는가? 그렇게 생각하면 위의 (1) 식에서 $\sigma_1^2$ 과 $\sigma_2^2$ 에 불편추정량 $S_1^2$ 과 $S_2^2$을 넣어 T분포를 따르는 통계량이라고 주장하고 싶다. 하지만 실제로 해보면 그렇지 않음을 쉽게 확인할 수 있다. 이 공식은 알려진 간단한 예시일 뿐, 통계학에서 검정을 할 때 공식이 있다는 생각은 위험하다.

이 문제들을 풀며 통계학이 무엇인가에 대해 나만의 생각을 좀 더 정리할 수 있었던 것 같다. 모든 상황에 확률이 존재하지만, 이를 수치화하는 것은 쉽지 않다. 상황에서 관측한 값들을 통해 우리가 분석할 수 있는 확률분포를 따르는 값을 뽑아내는 것, 그리고 이 값을 되도록 효과적으로 뽑아내는 것이 중요한 것이 아닌가 하는 생각이 들었다.

(추가) Fisher의 z 변환으로도 비슷한 이야기를 할 수 있지 않을까 싶다.

문제 2

단순선형회귀 모형
$Y_i = \alpha + \beta x_i + \epsilon_i, \ \epsilon_i \overset{\text{i.i.d.}}{\sim} N(0, \sigma^2)$
을 생각하자.
$H_0: \beta = 0$ 하에서 $ F = \dfrac{SSR/1}{SSE/(n-2)} \sim F(1, n-2)$ 임을 이용해 회귀직선의 유의성을 검정할 수 있음이 알려져 있다. $SSR$과 $SSE$가 독립임을 알고 있다고 할 때, 위의 검정통계량이 F분포를 따름을 보여라.

ANOVA에서도 비슷한 사실을 확인할 수 있다. 다음 One-Way ANOVA 모형을 생각하자.

$$```
$$\left{ \begin{aligned}
& y\_{ij} = \mu + \alpha\_i + \epsilon\_{ij} \quad (1 \le i \le k, 1 \le j \le n\_i) \\
& \epsilon\_{ij} \overset{i.i.d.}{\sim} N(0, \sigma^2) \\
& \sum\_{i=1}^k n\_i \alpha\_i = 0
\end{aligned}
\right.$$

$$

$H_0: \alpha_i = 0 \ (i = 1, 2, \cdots , k) $ 하에서 $F = \dfrac{SS_{tr}/(k-1)}{SSE/(N-k)} = \dfrac{MS_{tr}}{MSE} \sim F(k-1, N-k) $ 임을 이용해 그룹 간 차이의 유의성을 검정할 수 있다. $SS_{tr}$ 와 $SSE$는 독립임을 알고 있다고 할 때, 위의 검정통계량이 F분포를 따름을 보여라. $N = \sum_{i=1}^k n_i$ 이다.


### 해설 (Solution)

1.  $\dfrac{SSR}{\sigma^2} \sim \chi^2(1), \dfrac{SSE}{\sigma^2} \sim \chi^2(n-2)$ 임을 보이면 된다.

    $SSR = \sum_{i=1}^{n} (\hat{y_i} - \bar{y})^2$ 이다. $\hat{y_i} = \hat{\alpha} + \hat{\beta}x_i, \ \bar{y} = \hat{\alpha} + \hat{\beta}\bar{x}$ 임을 이용하면 $SSR = \hat{\beta}^2 S_{xx}$ 를 얻는다.

    $\hat{\beta} \sim N \left( \beta, \ \dfrac{\sigma^2}{S_{xx}} \right)$ 를 정규화하면 $Z = \dfrac{\hat{\beta} - \beta}{\sigma/ \sqrt{S_{xx}}} \sim N(0, 1)$ 이다. $\\beta = 0 $ 일 때 $\dfrac{SSR}{\sigma^2} = Z^2 = \chi^2(1)$ 이 됨을 알 수 있다.

    $SSE = \sum_{i=1}^{n} (y_i - \hat{y_i})^2$ 이다. $\mathbf{\hat{y}} = \begin{bmatrix}
    \hat{y_1} \\
    \vdots \\
    \hat{y_n}
    \end{bmatrix}$이 $\mathbf{y} =
    \begin{bmatrix}
    y_1 \\
    \vdots \\
    y_n
    \end{bmatrix}$의 $\mathbf{X} = \begin{bmatrix}
    1 & x_1 \\
    \vdots & \vdots \\
    1 & x_n
    \end{bmatrix}$
    의 column space로의 정사영으로 볼 수 있으므로, $\mathbf{\hat{y}}-\mathbf{y}$는 $\mathbf{y}$의 $C(X)^{\perp}$로의 정사영. $dim(C(X)^{\perp})=n-2$이므로 $\dfrac{SSE}{\sigma^2} \sim \chi^2(n-2)$

    마지막 부분의 조금 더 자세한 설명은 다음 [링크](https://rmunuu.github.io/blog/2025/%ED%91%9C%EB%B3%B8%EB%B6%84%EC%82%B0%EC%9D%B4-%EC%B9%B4%EC%9D%B4%EC%A0%9C%EA%B3%B1\(n-1\)%EC%9D%84-%EB%94%B0%EB%A5%B4%EB%8A%94-%EC%9D%B4%EC%9C%A0/) 를 참고하라.

2.  마찬가지로 $\dfrac{SS_{tr}}{\sigma^2} \sim \chi^2(k-1), \dfrac{SSE}{\sigma^2} \sim \chi^2(N-k)$ 임을 보이면 된다.

    $\\bar{y\_{i \\cdot}} = \\mu + \\alpha\_i + \\bar{\\epsilon\_{i \\cdot}}, \\ \\bar{y\_{\\cdot \\cdot}} = \\mu + \\bar{\\epsilon\_{\\cdot \\cdot}} $을 생각하자.

    $$
    $$$$SS\_{tr} = \\sum\_{i=1}^k n\_i(\\bar{y\_{i \\cdot}} - \\bar{y\_{\\cdot \\cdot}})^2
    \= \\sum\_{i=1}^k n\_i(\\alpha\_i + \\bar{\\epsilon\_{i \\cdot}} - \\bar{\\epsilon\_{\\cdot \\cdot}})^2
    \= \\sum\_{i=1}^k n\_i \\alpha\_i^2 + \\sum\_{i=1}^k n\_i (\\bar{\\epsilon\_{i \\cdot}} - \\bar{\\epsilon\_{\\cdot \\cdot}})^2

    $$
    $$$$$\bar{\epsilon_{i \cdot}} = \dfrac{\epsilon_{i1} + \cdots + \epsilon_{in_i}}{n_i}$ 인데 $\epsilon_{ij} \overset{i.i.d.}{\sim} N(0, \sigma^2)$이므로 $\bar{\epsilon_{i \cdot}} \sim N(0, \sigma^2/n_i)$이다. $H\_0: \\alpha\_i = 0 \\ (i = 1, 2, \\cdots , k) $ 하에서 생각하면 $\dfrac{SS_{tr}}{\sigma^2}$은 2(1)과 비슷한 논리로 $\chi^2(k-1)$을 따른다(표본분산의 경우와 동일).

    $$
    $$$$SSE = \\sum\_{i=1}^k \\sum\_{j=1}^{n\_i} (y\_{ij} - \\bar{y\_{i \\cdot}})^2

    $$
    $$$$위의 식을 각 i에 대해 생각하면, 각 수준에서 표본분산을 구하는 것과 비슷함을 알 수 있다. 따라서 각 i에서 합은 자유도 $ \chi^2(n_i - 1)$ 을 따른다. 각 수준에서 이 합이 독립이므로, 총합은 $\chi^2(N-k)$ 를 따른다.

### 부연 설명 (Explanation)

이 문제를 통해서, 선형회귀 모형과 ANOVA에서 유의성을 검정할 때 검정통계량이 따르는 분포가 어떻게 되는지 수학적으로 엄밀하게 보일 수 있었다. 검정통계량이 F분포를 따른다는 것을 보이기 위해 분모와 분자가 각각 카이제곱 분포를 따름을 보여야 했다. 이 과정에서 공통적으로 쓰인 아이디어는 **표준정규분포를 차원 k 부분공간에 사영한 벡터의 norm은 $\mathbf{\chi^2(k)}$를 따른다** 이다. 이는 n개 표본에서 표본분산이 $\chi^2(n-1)$을 따르는 이유를 증명하는데서 쓰이는 아이디어로, [링크](https://rmunuu.github.io/blog/2025/%ED%91%9C%EB%B3%B8%EB%B6%84%EC%82%B0%EC%9D%B4-%EC%B9%B4%EC%9D%B4%EC%A0%9C%EA%B3%B1\(n-1\)%EC%9D%84-%EB%94%B0%EB%A5%B4%EB%8A%94-%EC%9D%B4%EC%9C%A0/)를 읽거나 Cochran's theorem을 찾아볼 것을 추천한다. (2(1) solution의 링크와 같은 링크이다)

## 문제 3

다음의 사실이 알려져 있다.

> 두 확률변수 X, Y가 정규분포를 따를 때, $Cov(X, Y) = 0$ 이면 $X \perp\!\!\!\perp Y$

1.  One-Way ANOVA에서 $\bar{\epsilon_{i \cdot}} - \bar{\epsilon_{\cdot \cdot}} \perp\!\!\!\perp \bar{\epsilon_{\cdot \cdot}}$ 임을 보여라.
2.  $X\_i \\overset{i.i.d.}{\\sim} N(\\mu, \\sigma^2) $ 일 때 $X_i - \bar{X} \perp\!\!\!\perp \bar{X}$ 임을 보여라.
3.  단순선형회귀 모형에서 $e_i = y_i - \hat{y_i}$ 이라 할 때, $e_i \perp\!\!\!\perp \hat{y_i}$ 임을 보여라.

### 해설 (Solution)

1.  $\bar{\epsilon_{i \cdot}} - \bar{\epsilon_{\cdot \cdot}}$ 와 $\bar{\epsilon_{\cdot \cdot}}$ 는 모두 정규분포를 따른다. 따라서 $Cov(\\bar{\\epsilon\_{i \\cdot}} - \\bar{\\epsilon\_{\\cdot \\cdot}}, \\bar{\\epsilon\_{\\cdot \\cdot}}) = 0 $임을 보이면 된다. 이를 Cov의 선형성을 이용해 다시 정리하면$ Cov(\\bar{\\epsilon\_{i \\cdot}}, \\bar{\\epsilon\_{\\cdot \\cdot}}) = Cov( \\bar{\\epsilon\_{\\cdot \\cdot}}, \\bar{\\epsilon\_{\\cdot \\cdot}}) = Var(\\bar{\\epsilon\_{\\cdot \\cdot}}) $ 를 보이면 된다.

    $Cov( \bar{\epsilon_{\cdot \cdot}}, \bar{\epsilon_{\cdot \cdot}})$ 를 계산하는데는 Cov의 선형성이 유용하게 쓰인다. 각각을 $\epsilon_{ij}$ 들의 선형결합으로 생각하면, $Cov(\\epsilon\_{i\_1 j\_1}, \\epsilon\_{i\_2 j\_2}) = \\delta\_{i\_1 i\_2} \\delta\_{j\_1 j\_2} $임을 이용해 간단하게 값을 구할 수 있다. ($ \\delta$ : Kronecker delta)

    $ \\bar{\\epsilon\_{i \\cdot}} = \\dfrac{\\epsilon\_{i1} + \\cdots + \\epsilon\_{in\_i}}{n\_i} $, $\bar{\epsilon_{\cdot \cdot}} = \dfrac{\epsilon_{11} + \cdots + \epsilon_{kn_k}}{N}$ 이므로 $Cov( \\bar{\\epsilon\_{\\cdot \\cdot}}, \\bar{\\epsilon\_{\\cdot \\cdot}}) = \\dfrac{1}{n\_i N} \\cdot n\_i \\sigma^2 = \\dfrac{\\sigma^2}{N} $

    $Var(\bar{\epsilon_{\cdot \cdot}}) = \dfrac{\sigma^2}{N}$ 이므로, 같음을 증명했다. 따라서 $\bar{\epsilon_{i \cdot}} - \bar{\epsilon_{\cdot \cdot}} \perp\!\!\!\perp \bar{\epsilon_{\cdot \cdot}}$

2.  마찬가지로 $ Cov(X_i, \bar{X}) = Var(\bar{X})$ 임을 보이면 된다. $\bar{X} = \dfrac{X_1 + \cdots + X_n}{n}$ 이므로 Cov의 선형성을 이용하면 $ Cov(X\_i, \\bar{X}) = \\dfrac{\\sigma^2}{n} $, $Var(\bar{X}) = \dfrac{\sigma^2}{n}$ 이므로 같음이 증명되었다.

3.  마찬가지로 $Cov(y_i, \hat{y_i}) = Var(\hat{y_i})$ 임을 보이자.

    $$
    $$$$Cov(y\_i, \\hat{y\_i}) = Cov(\\epsilon\_i, \\hat{\\alpha}+\\hat{\\beta}x\_i)

### 부연 설명 (Explanation)

3번의 (1), (2), (3)은 사실 똑같이 생긴 문제들이다. 2번에서도 말하던 직교성과 독립의 관계를 직접 몸으로 느껴보는 과정이다. 실제로 필자도 문제를 풀면서 공분산이 0이 나올 때 어떤 이유에서 그것들의 공분산이 0이 되는건지 궁금해한 것에서, 또 확률변수가 독립인 숨겨진 이유가 있다면 공분산을 복잡한 계산 없이 0이라고 할 수 있지 않을까에서 시작되었다. 결론적으로 위의 문제들은 Cov의 선형성을 이용해 전개해 계산한다면 모두 다른 문제 같지만 결론적으로 모두 (2)의 꼴을 띈 같은 문제이다.

공분산은 내적과 비슷한 성질이 많은 것 같다. 공분산의 선형성도 그렇고, 이 문제에서 볼 수 있듯 정규분포의 경우에는 확률변수들을 벡터처럼 생각했을 때 벡터끼리 수직이면 공분산의 값도 0이다. 공분산을 내적처럼 생각할 수 있는 것인지 아직 정확하게 밝혀내지는 못했는데, 한 사람이 있다면 알려주세요. :)
